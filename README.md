* **Оюутан:** Э.Мишээл (Мэдээллийн Системийн Менежмент)

## 1. Сэдвийн танилцуулга ба өөрийн тогтоосон дүрмүүд
Улаанбаатар хотын агаарын бохирдлын түвшинг 7 хоногийн турш хэмжиж, AQI индекс болон өөрийн тогтоосон хязгаарлалтын дагуу ангилах, мөн хамгийн бохир 3 өдрийг өдрийн дугаартай нь хамт эрэмбэлж гаргах программ юм.

### Өөрийн тогтоосон дүрмүүд (AQI ангилал ба хязгаарууд):
* **Оролтын зөвшөөрөгдөх хязгаар:** (0 <= pm <= 500`)
* **0 - 50:** Сайн
* **51 - 100:** Дунд зэрэг
* **101 - 150:** Хүний эрүүл мэндэд сөрөг нөлөөтэй
* **151 - 200:** Муу
* **201 - 500:** Аюултай

## 2. Ашигласан элементүүд
Програмд даалгаврын шаардлагын дагуу дараах үндсэн элементүүд орсон болно:
* **Оролт / Гаралт:** `scanf` ашиглан 7 хоногийн утгыг авч, `printf`-ээр үр дүнг хүснэгт хэлбэрээр багануудыг тэгшилж (`%-10s`, `%8.2f`) хэвлэсэн.
* **Үйлдэл ба илэрхийлэл:** Арифметик (`sum / 7`) болон логик (`&&`, `||`) үйлдлүүдийг ашигласан.
* **Нөхцөл:** `else-if` шатлал ашиглан AQI ангиллыг тодорхойлсон.
* **Давталт ба хүснэгт:** `for` давталт ашиглан 7 мөр бүхий хүснэгтийг хэвлэсэн.
* **Дэд алгоритм:** Flowgorithm дээр `GetAQIClass` функц үүсгэж, Main-аас дуудсан.
* **Эрэмбэлэлт / Хайлт:** Давталт ашиглан 7 хоногийн утгуудаас хамгийн бохир 3 өдрийг өдрийн дугаартай нь хамт эрэмбэлж гаргасан.
* **Оролтын шалгалт:** Буруу утга (сөрөг тоо эсвэл 500-аас их) орж ирвэл `do-while` давталтаар алдаа зааж дахин шаардсан.
